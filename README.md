# Foldlight

Infinite nested light. Trap a picture. Steer it as far as the loop will go.

Live: **https://yoans.github.io/foldlight/** (GitHub Pages). Custom domain next: `foldlight.buildbeyondbelief.com`.

After [Dave Blair’s Light Herder](https://www.thelightherder.com/) and [Peter King’s 1997 glass](https://sweetandfizzy.com/fractals/).

```bash
npm install
npm run dev
```

## Play

Pick a session chip or **Surprise me**. **Trap** locks a picture (double-tap on a phone). **Scale** is depth — smaller means more nested copies. Open **Console** for the whole desk.
